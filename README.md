# RedShop

RedShop is a deliberately vulnerable e-commerce application built as a practical web application security lab.

The project is developed in phases: first a functional/security baseline, then controlled vulnerabilities for exploitation, analysis, remediation, and retesting.

## Current State

- Phase 1 — Product + Category: **Completed**
- Phase 2 — User + Authentication: **Completed**
- Phase 3 — Cart + Checkout + Order: **Completed**
- Phase 4 — REST API + API Authentication/Authorization: **Completed**
- Phase 5 — Admin + Roles + Admin Operations: **Completed**
- Phase 6 — Intentional Vulnerabilities: **Not started**

## Handoff

The most important continuation document is `docs/00-project-state.md`. It describes the project state at the end of Phase 5 so the project can be resumed later from the same point.
