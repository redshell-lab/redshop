# RedShop — Project Overview

## Purpose

RedShop is a deliberately vulnerable e-commerce application for learning web application development and application security.

## Functional Scope

- Products
- Categories
- Users
- Registration/login
- User account
- Shopping cart
- Checkout
- Orders
- REST APIs
- Admin panel

## Security Learning Scope

Phase 6 will cover:

- XSS
- SQL Injection
- IDOR / Broken Access Control
- SSRF
- File Upload
- Race Conditions
- Business Logic flaws

## Development Strategy

Phases 1–5 establish the functional and security baseline. Phase 6 introduces controlled weaknesses one at a time.

The intended learning cycle is:

```text
Feature → Secure baseline → Intentional vulnerability → Exploit → Root cause → Fix → Retest
```
